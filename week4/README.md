# คู่มือการเล่น D&D (ฉบับแปลไทย) — README

โปรเจกต์นี้เป็นเว็บไซต์แบบหลายหน้า (multi-page website) จำนวน **3 ไฟล์ HTML** ที่เชื่อมโยงถึงกันผ่านเมนูนำทางด้านบน (navbar) เหมือนกันทุกหน้า สร้างด้วย **Bootstrap 5.0.2** (สำหรับเลย์เอาต์/คอมโพเนนต์) และฟอนต์ Google Fonts สองตัวคือ *Sarabun* (เนื้อหาทั่วไป) และ *Noto Serif Thai* (หัวข้อ) ธีมสีเป็นโทน "ม่วงเข้ม–แดงเลือดหมู–กระดาษเก่า (parchment)" ให้ความรู้สึกเป็นแฟนตาซี/ยุคกลาง เหมาะกับธีมเกม D&D

จุดประสงค์รวมของเว็บไซต์: สอนกฎการเล่นเกม Dungeons & Dragons (D&D) เป็นภาษาไทย ตั้งแต่ส่วนประกอบของเกม กฎพื้นฐาน ไปจนถึงระบบการต่อสู้และเวทมนตร์อย่างง่าย

---

## 1. `index.html` — หน้าแรก (Homepage)

หน้าเปิดของเว็บไซต์ ทำหน้าที่แนะนำภาพรวมและชักชวนให้ผู้ใช้ไปอ่านรายละเอียดในหน้าอื่น

**โครงสร้างเนื้อหา:**
- **Hero Section**: ภาพพื้นหลังเต็มจอ (`BGindexmain.jpg`) พร้อมข้อความต้อนรับ ชื่อคู่มือ "คู่มือการเล่น D&D (Play Guide)" คำโปรยสั้น ๆ และปุ่ม 2 ปุ่มที่พาไปหน้า "กฎพื้นฐาน" (`rules.html`) และหน้า "การต่อสู้" (`combat_magic.html`)
- **ส่วนประกอบของเกม (Game Components)**: การ์ดแนะนำ 6 ใบ (เลย์เอาต์แบบกริด 3 คอลัมน์) แต่ละใบมีไอคอน ชื่อ คำอธิบายสั้น ๆ และปุ่มลิงก์ไปหน้าเนื้อหาที่เกี่ยวข้อง
- **Footer**: ลิขสิทธิ์ปี 2569 และลิงก์ซ้ำไปยัง 3 หน้าหลัก

**หน้าที่โดยสรุป:** เป็น "สารบัญ" ของเว็บไซต์ ไม่มีกฎละเอียดในตัวเอง แต่ทำหน้าที่พาไปยังหน้าที่มีเนื้อหาจริง

---

## 2. `rules.html` — กฎพื้นฐาน (Basic Rules)

หน้านี้อธิบายกลไกพื้นฐานที่สุดของเกมที่ผู้เล่นทุกคนต้องรู้ก่อนเริ่มเล่น แบ่งเป็นเนื้อหาหลัก (คอลัมน์ซ้าย 8/12 ส่วน) และแถบข้างเคล็ดลับ (คอลัมน์ขวา 4/12 ส่วน)

**หน้าที่โดยสรุป:** เป็นหน้า "ปูพื้นฐาน" สำหรับผู้เล่นใหม่ ครอบคลุมกลไกแกนกลางของเกมก่อนเข้าสู่การต่อสู้จริง

---

## 3. `combat_magic.html` — การต่อสู้, เวทมนตร์ และดัชนีคำศัพท์

หน้านี้เจาะลึกกลไกการต่อสู้และเวทมนตร์ ใช้ระบบ **แท็บ (Tabs)** 3 แท็บสลับเนื้อหาภายในหน้าเดียว

**หน้าที่โดยสรุป:** เป็นหน้า "ขั้นสูง" ที่รวมกฎการต่อสู้แบบละเอียด ระบบเวทมนตร์ และคำศัพท์อ้างอิงไว้ในที่เดียว โดยใช้ Tabs และ Modal ช่วยจัดระเบียบเนื้อหาจำนวนมากไม่ให้หน้ายาวเกินไป

---

## จุดร่วมทางเทคนิคของทั้ง 3 ไฟล์

- **Bootstrap 5.0.2** โหลดผ่าน CDN (`jsdelivr`) ทั้ง CSS และ JS bundle — ใช้สำหรับ grid layout, navbar, accordion, tabs, modal, badge ฯลฯ
- **ฟอนต์**: Sarabun (เนื้อหา) + Noto Serif Thai (หัวข้อ) โหลดจาก Google Fonts
- **CSS ตัวแปร (`:root`)**: กำหนดชุดสีธีม เช่น `--parchment`, `--crimson`, `--purple` ให้ใช้ร่วมกันในทุกหน้า (แต่แต่ละไฟล์ประกาศซ้ำในตัวเอง ไม่ได้แยกเป็นไฟล์ CSS กลาง)
- **โครงหน้าเหมือนกันทุกไฟล์**: navbar บนสุด → hero section พร้อมภาพพื้นหลัง → เนื้อหาหลักใน `<main>` → footer ล่างสุดที่มีลิงก์ไปทั้ง 3 หน้า
- **Accessibility**: มีการใส่ `skip-link` (ข้ามไปเนื้อหาหลัก), `aria-label`, `aria-labelledby`, `role` ต่าง ๆ ค่อนข้างครบถ้วนในทุกหน้า แสดงว่าตั้งใจออกแบบให้รองรับ screen reader
- **รูปภาพพื้นหลัง**: แต่ละหน้าอ้างอิงไฟล์รูปในโฟลเดอร์ `images/` (เช่น `BGindexmain.jpg`, `BGrule.jpg`, `BGcombat.jpg`) — **ไม่ได้แนบมาในชุดไฟล์นี้** จึงต้องมีโฟลเดอร์ `images/` วางคู่กับไฟล์ HTML เพื่อให้พื้นหลังแสดงผลถูกต้อง
